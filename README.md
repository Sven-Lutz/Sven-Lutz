## Selected work

### [INT — Experimental systems and research software](https://github.com/Sven-Lutz/INT)

Python-based software for laboratory process control, including filtration and Aqua systems. The repository covers hardware integration, PySide6 operator interfaces, telemetry and data logging, with project-specific technical documentation.

### [EV Charging — Bachelor's thesis](https://github.com/Sven-Lutz/BA_EV_Charging)

*User-Centric Time Series Forecasting for EV Charging Stations.* Research on charging-station load forecasting using Gaussian mixture clustering and LSTM networks. The repository currently contains the thesis report.

### [POLIANNA — Climate-policy NLP](https://github.com/Sven-Lutz/SA_Polianna)

A completed student research project exploring ClimateBERT and sampling strategies for classifying climate-policy text. Includes the report, experimental notebook and recorded results. The original evaluation has methodological limitations; the reported scores should not be treated as independently validated generalization performance.

### [Computer Vision Foosball — Team project](https://github.com/Sven-Lutz/EDV4_Tischkicker)

A hands-on team project exploring webcam-based ball tracking, goal detection and game statistics with Python and OpenCV.
